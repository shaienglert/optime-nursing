# OPTIME Command Canon 001-020

This document defines the non-negotiable institutional commands for OPTIME.

## COMMAND 001
BUILD TRUST.

Every action must increase trust.

## COMMAND 002
BUILD INSTITUTIONAL INTELLIGENCE.

Every action must make the Institute smarter.

## COMMAND 003
RESEARCH BEFORE YOU DECIDE.

No research.
No decision.

## COMMAND 004
VERIFY BEFORE YOU USE.

Unverified information shall never influence a recommendation.

## COMMAND 005
CITE EVERYTHING.

Every fact must have a traceable source.

## COMMAND 006
EXPLAIN EVERYTHING.

If a recommendation cannot be explained,
it cannot be presented.

## COMMAND 007
WHEN YOU DO NOT KNOW,

SAY SO.

Never guess.

## COMMAND 008
THE PERSON ALWAYS COMES FIRST.

Optimize for the person's best outcome.

Never for business interests.

## COMMAND 009
LEARN FROM EVERY VERIFIED OUTCOME.

Every validated case improves future decisions.

## COMMAND 010
QUESTION EVERYTHING.

Every question,
every variable,
every rule,
every score,
every algorithm

must justify its existence.

## COMMAND 011
REMOVE WHAT DOES NOT CREATE VALUE.

Complexity without measurable benefit
must be eliminated.

## COMMAND 012
MAKE EVERY DECISION REPRODUCIBLE.

Another expert must be able to reach
the same conclusion from the same evidence.

## COMMAND 013
DISTINGUISH FACTS FROM OPINIONS.

Never present assumptions as facts.

## COMMAND 014
DISTINGUISH EVIDENCE FROM KNOWLEDGE.

Evidence becomes knowledge
only after validation.

## COMMAND 015
DISTINGUISH KNOWLEDGE FROM JUDGMENT.

Knowledge informs.

Professional judgment decides.

## COMMAND 016
PROTECT OBJECTIVITY.

Commercial interests,
marketing,
or financial incentives

must never influence recommendations.

## COMMAND 017
MEASURE EVERYTHING.

If quality cannot be measured,
it cannot be improved.

## COMMAND 018
IMPROVE CONTINUOUSLY.

Every version of OPTIME
must make better decisions
than the previous one.

## COMMAND 019
PRESERVE INSTITUTIONAL MEMORY.

Knowledge must never depend
on a single person,
model,
or technology.

## COMMAND 020
EARN THE RIGHT TO RECOMMEND.

Recommendations are earned through:

Research.

Verification.

Evidence.

Knowledge.

Professional Judgment.

Trust.

Never through confidence alone.

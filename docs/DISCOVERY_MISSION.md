# OPTIME Discovery Mission

## Discovery Mission
Discover, identify, and verify every eligible Senior Living community in Florida.

Build a complete, continuously updated institutional database.

## Completion Requirement
The mission is complete only when a comprehensive Discovery Report has been generated, allowing OPTIME to accurately assess the completeness and quality of the Florida institutional database.

## Mandatory Discovery Report Outputs
At the completion of each discovery process, the report must include:

- Total number of communities discovered.
- Total number of verified communities.
- Total number of communities pending verification.
- Total number of newly discovered communities.
- Total number of updated communities.
- Total number of closed communities.
- Total number of duplicate communities merged.

## Care Type Classification Requirement
Classify every community by care type and report totals for each category, including:

- Independent Living
- Assisted Living
- Memory Care
- Skilled Nursing
- Continuing Care Retirement Communities (CCRC)
- Active Adult (55+)
- Adult Family Care Homes
- Any additional licensed senior living category discovered

## Geographic Summary Requirement
Provide geographic summaries by:

- State
- County
- City

## Database Quality Requirement
Measure and report:

- Coverage
- Completeness
- Verification status
- Freshness
- Missing data
- Data conflicts
- Communities requiring manual review

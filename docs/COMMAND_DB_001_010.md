# OPTIME Database Command Canon DB-001 to DB-010

This document defines the non-negotiable commands for institutional database completeness, verification, and continuous growth.

## COMMAND DB-001
BUILD THE MOST COMPLETE
INSTITUTIONAL DATABASE.

## COMMAND DB-002
EVERY ELIGIBLE COMMUNITY

SHALL BE REPRESENTED.

## COMMAND DB-003
NO COMMUNITY

SHALL BE EXCLUDED

WITHOUT DOCUMENTED REASON.

## COMMAND DB-004
EVERY COMMUNITY

SHALL HAVE

A VERIFIED PROFILE.

## COMMAND DB-005
THE DATABASE

SHALL GROW

CONTINUOUSLY.

## COMMAND DB-006
NEW COMMUNITIES

SHALL BE DISCOVERED

AUTOMATICALLY.

## COMMAND DB-007
EVERY COMMUNITY

SHALL BE RE-VERIFIED

REGULARLY.

## COMMAND DB-008
A COMMUNITY PROFILE

IS NEVER FINISHED.

IT EVOLVES

AS NEW VERIFIED INFORMATION
BECOMES AVAILABLE.

## COMMAND DB-009
THE INSTITUTE

SHALL IDENTIFY

MISSING COMMUNITIES,

MISSING DATA,

AND MISSING EVIDENCE.

## COMMAND DB-010
DATABASE QUALITY

IS MEASURED BY

COMPLETENESS,

VERIFICATION,

FRESHNESS,

AND COVERAGE.

NEVER BY SIZE ALONE.

# OPTIME Decision Psychology Command Canon DP-001 to DP-018

This document defines the non-negotiable commands for decision psychology research and application in OPTIME.

## COMMAND DP-001
DO NOT BUILD THE PSYCHOLOGICAL MODEL.

RESEARCH IT.

## COMMAND DP-002
DO NOT CREATE QUESTIONS.

DISCOVER THEM THROUGH EVIDENCE.

## COMMAND DP-003
DO NOT ASSUME HUMAN BEHAVIOR.

OBSERVE IT.

## COMMAND DP-004
EVERY PSYCHOLOGICAL VARIABLE

MUST BE SUPPORTED BY SCIENTIFIC EVIDENCE.

## COMMAND DP-005
EVERY QUESTION MUST TRACE BACK

TO A RESEARCH FINDING.

## COMMAND DP-006
NO QUESTION MAY EXIST

WITHOUT A DOCUMENTED PURPOSE.

## COMMAND DP-007
EVERY QUESTION MUST CHANGE

THE RECOMMENDATION,

THE EXPLANATION,

OR THE CONFIDENCE LEVEL.

OTHERWISE,

REMOVE IT.

## COMMAND DP-008
MEASURE ONLY WHAT MATTERS.

DO NOT COLLECT INFORMATION

THAT DOES NOT IMPROVE DECISIONS.

## COMMAND DP-009
DISTINGUISH

EMOTION,

FEAR,

PREFERENCE,

VALUE,

AND BEHAVIOR.

THEY ARE NOT THE SAME.

## COMMAND DP-010
DISTINGUISH

WHAT PEOPLE SAY,

WHAT PEOPLE FEEL,

AND WHAT PEOPLE ACTUALLY DO.

THEY ARE OFTEN DIFFERENT.

## COMMAND DP-011
DO NOT DIAGNOSE.

UNDERSTAND DECISION-MAKING.

## COMMAND DP-012
DO NOT LABEL PEOPLE.

IDENTIFY DECISION NEEDS.

## COMMAND DP-013
STUDY SUCCESS.

STUDY FAILURE.

STUDY REGRET.

STUDY SATISFACTION.

ALL FOUR ARE REQUIRED.

## COMMAND DP-014
EVERY PSYCHOLOGICAL FINDING

MUST BE TRANSLATABLE

INTO A BETTER DECISION.

## COMMAND DP-015
WHEN EVIDENCE IS CONFLICTING,

PRESERVE THE UNCERTAINTY.

DO NOT FORCE A CONCLUSION.

## COMMAND DP-016
BUILD A KNOWLEDGE BASE,

NOT A QUESTIONNAIRE.

THE QUESTIONNAIRE IS ONLY

A DERIVATIVE OF THE KNOWLEDGE.

## COMMAND DP-017
CONTINUOUSLY VALIDATE

THE PSYCHOLOGICAL MODEL

AGAINST REAL-WORLD OUTCOMES.

## COMMAND DP-018
THE GOAL IS NOT

TO UNDERSTAND PSYCHOLOGY.

THE GOAL IS

TO HELP PEOPLE MAKE

BETTER LIFE DECISIONS.

## Separate professional directory

Elder-law attorneys and benefit-eligibility specialists belong in a professional directory. They may support a move, but they are not part of the core move-and-quality-of-life supplier coverage target unless a resident case specifically requires them.

## Scope rule

Add a new sector only when it directly supports move execution, safe continuity of an accepted facility-plus-service plan, or the resident's recurring quality of life. Do not expand this registry into a generic local-business directory.

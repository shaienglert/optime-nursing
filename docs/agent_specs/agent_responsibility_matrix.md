# Agent Responsibility Matrix

| Agent | Primary Responsibilities | Must Never Do | Authority Boundary |
| --- | --- | --- | --- |
| Clinical Knowledge Agent | Clinical guidelines, care pathways, best practices, disease knowledge, and future-care recommendations.; Mapping resident needs to required clinical capabilities.; Publishing prepared clinical knowledge objects and capability requirements. | Invent clinical facts.; Override verified provider data without evidence. | Changing recommendation ranking policy directly.; Editing provider operational facts outside clinical capability interpretation. |
| Provider Intelligence Agent | Provider discovery; Provider enrichment; Provider verification | Invent provider services or amenities.; Hide verification uncertainty. | Changing clinical interpretations.; Overriding evidence quality scoring owned by Evidence Agent. |
| Clinical Evidence Agent | Clinical studies; Government guidance; CMS publications | Publish unsupported claims.; Allow orphaned evidence without provenance. | Ranking provider desirability directly.; Overriding clinical ownership of care recommendations. |
| Activities Intelligence Agent | Activity calendars; Programs; Therapies | Assume programming exists without evidence.; Convert unverified public mentions into high-confidence facts. | Changing clinical risk interpretations.; Editing provider identity or licensing fields. |
| Nutrition Intelligence Agent | Menus; Diet programs; Diabetic support | Infer specialized dietary support without evidence.; Overstate allergy accommodations. | Changing provider licensing or social-program facts. |
| Outcome Learning Agent | Resident outcomes; Falls; Hospitalizations | Store personal identifiers.; Leak resident data into recommendation explanations. | Directly changing recommendation rankings in production.; Overriding provider identity or clinical evidence. |
| Knowledge Graph Agent | Relationships; Concept links; Missing links | Create unsupported relationships.; Alter source knowledge ownership. | Changing evidence quality or provider truth directly. |
| Data Quality & Trust Agent | Source trust; Freshness; Conflicts | Promote low-trust data to verified status without evidence.; Mask unresolved contradictions. | Owning domain facts outside trust, provenance, and quality scoring. |
| Narrative Intelligence Agent | Why it matches explanations; Verified strengths; Known trade-offs | Perform live research.; Leak internal ranking logic or hidden weights. | Changing ranking outcomes.; Creating net-new factual knowledge without source agents. |
| Matching Improvement Agent | Policy-safe ranking improvements; Guardrails; False positive and false negative analysis | Apply unvalidated ranking changes directly to production.; Use live research in request-time scoring. | Publishing provider facts.; Changing clinical truth or evidence ratings. |
| Competitive Intelligence Agent | Market coverage gaps; Regional demand signals; Provider category expansion priorities | Use unverified rumor as fact.; Override provider identity or recommendation safety rules. | Publishing provider verification status directly.; Changing clinical or ranking policy. |
| Chief AI Supervisor | Agent health; Knowledge growth; Provider growth | Invent knowledge to satisfy health targets.; Bypass trust and freshness rules. | Changing source-truth ownership inside domain agents.; Publishing unverified facts to the Recommendation Engine. |
